# Тестирование API сайта https://qa-scooter.praktikum-services.ru/
## Документация находится https://qa-scooter.praktikum-services.ru/docs/
В проекте реализованы тесты с использование фреймворка `pytest`
Тесты расположены в папке `tests`.
Ручки расположены в папке `api_objects`
## Проект
### Тесты
Тестируются ручки. На корректность работы и выдачи нужных ошибок.

- Проверяет принятие заказа с несуществующим индикатором курьера (`test_accept_order.py`)
- Проверяет создание курьера, невозможность создания двух одинаковых курьеров, ошибка при создании без обязательного поля (`test_create_courier.py`)
- Проверят создание заказа с разными цветами (`test_create_order.py`)
- Проверяет успешное удаление курьера, ошибку при удаления без индефикатора, ошибка удаления с несуществующем ID (`test_delete_courier.py`)
- Проверяет успешное отслеживание заказа по номеру (`test_get_order.py`)
- Проверяет получение списков заказа (`test_list_orders.py`)
- Проверяет успешную авторизацию курьера и ошибку при неккоректном паролу (`test_login_courier.py`)

## Запустить тесты 
pytest -v 
## Установить зависимости 
pip install -r requirements.txt
